# v0.5.1：工具候选栏与清空撤回

本版按确认的交互更新：回车键上滑清空整个输入框，下滑恢复上一次清空的文字。普通点按仍执行输入框原本的回车动作。

## 顶部布局

- 空闲时，顶部一行显示「帮我回答」「风格」「设置」。
- 输入拼音、英文或九宫格时，同一位置显示候选词，工具栏隐藏。
- 手写产生候选后，也使用这一行；选词并清除笔画后返回工具栏。
- 候选为空且没有正在输入的拼音或笔画时，恢复工具栏。
- 删除常驻的「中文 · 连续拼音与简拼」和「点帮我回答……」说明行，不再为它们保留空白高度。
- 工具行与候选行同为 40 dp，切换时键盘位置保持不变。
- 只有主动使用 AI 回复时才显示必要的进度、错误或屏幕预览。

## 回车键

| 手势 | 行为 |
| --- | --- |
| 点按 `↵` | 保留原有回车行为；所在应用可能换行、搜索或发送 |
| 上滑 | 松手后清空整个输入框；清除正在输入的拼音、手写候选，恢复工具栏 |
| 下滑 | 松手后恢复本次输入会话中上一次清空的文字及光标/选区；拼音和英文编辑状态一并恢复 |
| 滑回起点 | 恢复为普通回车 |
| 取消触摸 | 不执行清空、撤回或回车 |

滑动时，小预览会显示「清空」或「撤回」。这两个方向固定，不随字母键的符号滑动设置改变。

撤回仅针对上一回清空：清空后已经输入或粘贴新内容，不会用旧内容覆盖它；隐藏键盘、切换输入框或输入模式后，不保留旧输入框的恢复记录。清空一个已经为空的输入框，不会丢掉上一回清空的记录。

恢复记录只暂存在内存，不写入词库、文件、剪贴板或 API。密码输入框和不能提供完整可编辑文字的输入框不执行这一组合操作。不支持的输入框会显示提示，保留原文字。

## 自检处理

1. 先结束拼音编辑，再全选并清空，避免输入框只删除正在编辑的拼音而保留前后文字。
2. 检查完整文字快照与光标两侧内容一致，避免把部分截取当作整个输入框。
3. 撤回前确认仍在同一输入连接、且当前输入框为空；新文字不能被旧快照覆盖。
4. 恢复拼音时重新标记原来的编辑范围，避免继续打字产生重复文本。
5. 切换模式、关闭键盘与销毁服务时清理临时恢复记录。
6. 保留用户修改的首页「❤❤❤」和「外观」文案；列表箭头同步放大。
7. 修正按键预览切换文字后的尺寸更新，确保「清空」「撤回」完整显示在小预览内。

## 验证

Android 36 / Pixel 6 模拟器中的实际操作检查覆盖 17 项：顶部切换、键盘位置、拼音清空/恢复、继续拼音输入、粘贴后保护、多行及表情、重复空清空、普通回车、输入后保护、隐藏后清理，以及英文、九宫格和手写。

新增 15 项实际 EditText/InputConnection 检查覆盖光标两侧与选区、Unicode 和多行、编辑中的拼音、重复清空、新输入保护、不同输入框、局部截取、截断、拒绝编辑与主动丢弃。

46 项按键、布局与照片检查通过，覆盖了回车上滑、下滑、预览文字完整显示、滑回起点、水平移动和取消。编译成功，Lint 0 错误、21 提示。结果及 APK 校验信息保存在本机 `release/v0.5.1-验证结果.json`。

真实手机、微信/QQ 和长期连续使用仍需试用。本次未调用真实模型 API。
