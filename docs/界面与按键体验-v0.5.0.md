# v0.5.0 · 界面与按键体验

这次更新处理松手输入、长按删除、符号预览，以及外观设置中不直观的参数操作。原有用户词库、API 配置和界面语言继续保留。

## 使用

安装 `release/控机AI输入法-v0.5.0.apk`，覆盖安装即可，不需要卸载旧版。

打开「私人定制键盘外观」：

1. 选择 26 键、九宫格或手写。
2. 点「拖拽编辑」，拖动键盘移动；缩窄后可左右移动，拖右下角圆形手柄调整宽度和高度。
3. 点「结束编辑」试按键。尺寸和位置设有边界，避免拖出显示区域或把按键缩得过小。
4. 选择「白色」或「深色」；「导入照片背景」打开系统图片选择器，选择一张图片作为键盘背景。
5. 「快捷符号」中设置小字位置和上滑/下滑方向。
6. 点「应用到键盘」保存，或点「应用并试打」马上体验。

未应用的调整不会覆盖已保存的设置。「恢复默认外观」恢复标准尺寸与位置，主题、照片、模式继续保留。「移除照片背景」不删除相册中的原图。

## 输入行为

- 按下不输出，松手才确认。手指轻微滑出按键，仍输入最初按下的按键。
- 沿配置方向垂直滑动，预览块切换为符号；滑回起点又切回字母。松手只输出当前选择一次。
- 小预览块固定为 38 × 46 dp，位于按键上方，只绘制在本应用窗口中，不需要悬浮窗权限。
- 按住字母不触发长按符号；符号通过滑动或符号页输入。
- 删除键轻点删一个字；按住约 380 ms 后，每 75 ms 删一个 Unicode 码点。松手、取消触摸、隐藏键盘或移除视图时停止，不再清空整段内容。
- 初始空输入不再插入「你好、谢谢、好的」等固定候选。正常输入 `nihao` 或九宫格 `64426` 仍可选择「你好」。
- 输入记忆持续保存在本机，可在「输入与词库设置」暂停或主动清空。

## 自检后移除与调整

移除了色号输入、点缀色选项、透明度、圆角、间距、字号、按键高度滑条、独立数字行和按压缩放动画等外观参数控件。原有 QWERTZ/AZERTY 布局偏好会保留，但不再在普通外观页堆放布局参数。

首页、词库、练习和语言页统一为黑白界面，以标题、分隔线和留白组织信息。保留原文案，较长的模型接口、屏幕读取和词库说明可以展开阅读。记忆开关与清空入口放在词库页前面。

按键不再依赖系统按钮滑出边界后取消点击的行为，也不再在松手时才第一次判断符号。候选刷新在主线程消息队列中合并，按键输出先执行；取消每次按压的缩放动画，减少输入时的视觉漂移。

照片在后台解码、最长边限制为 1600 像素后保存到应用专属目录。预览和键盘复用缓存，按键绘制时不读取图片文件；重启后仍可使用。照片不上传到模型接口。

## 实现入口

| 文件 | 职责 |
| --- | --- |
| `Glass.java` | 按键释放、滑动选择、小预览、删除重复与黑白表面 |
| `KeyboardFrame.java` | 预览与实际键盘共用的布局边界、拖动与缩放 |
| `KeyboardStyle.java` | 主题、几何位置、照片引用的保存与旧主题迁移 |
| `BackgroundPhoto.java` | 图片导入、限尺寸处理、本机副本与缓存 |
| `AppearanceActivity.java` | 图形编辑器、模式、主题、照片及快捷符号设置 |
| `Ui.java` / `LocalizedActivity.java` | 应用黑白主题、导航行与折叠说明 |
| `AiInputService.java` | 实际输入、候选刷新、密码输入保护及 AI 回复流程 |

## 验证与限制

测试使用 Android 36 Pixel 6 模拟器和内置练习对话，没有向真实模型 API 提交内容，也没有清空真实输入记忆。

本机编译成功；Android Lint 为 0 错误、22 条提示，涉及目标版本、程序创建的视图、原生开关、偏好保存与本地化。引擎检查 43 项、独立输入记忆检查 16 项、按键与布局检查 36 项通过。

实际模拟器中分别验证了上下滑选择、松手确认、长按逐字删除、拖动及右下角缩放、照片导入与重启恢复、九宫格选词、首笔手写自动识别、六种界面语言、横屏键盘及旋转后保留练习输入。UI 自动化整套脚本曾受模拟器 UiAutomation 崩溃和瞬时树影响中断，因此这些结果来自分段复测，不代表整套脚本一次运行全绿。真机手感仍需使用者试用。

可复现检查：

- `tests/EngineChecks.java`：中文连续组词、简拼、模糊/错序/邻键纠错、九宫格及学习排序。
- `MemoryChecksInstrumentation`：独立 SQLite 数据库中的保存、关闭重开、暂停记忆、清空与并发写入边界。
- `MemoryChecksInstrumentation -e suite keyboard`：真实附着视图与 MotionEvent，检查释放、取消、多指、预览位置、删除重复、拖拽缩放和照片处理。
- `tests/redesign_smoke.py`：实际模拟器输入法触摸、黑白主题、系统图片选择器、重启保存、三种模式与六种界面语言。

模拟器测试不等于实际手机长期体验验证。微信/QQ、各品牌系统、平板与长期连续使用仍需要真机验证；本版没有新接入云端输入预测或语义纠错。
