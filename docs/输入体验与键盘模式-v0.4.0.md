# 输入体验与键盘模式 v0.4.0

本机安装包：`D:\控机大师\release\控机AI输入法-v0.4.0.apk`。

Android 原生 Java 项目，支持 Android 11 及以上。本包为调试签名的测试版，约 40 MB，包含四种 CPU 架构的手写识别运行库。同应用 ID、同签名覆盖安装可保留原有设置和词库；不要通过卸载来更新需要保留记忆的安装。

## 三种键盘模式

打开应用 → **私人定制键盘外观** → **键盘模式** → 选择模式 → **应用到键盘**或**应用并试打**。

| 模式 | 行为 |
| --- | --- |
| 26 键 | 中文连续拼音、简拼、模糊拼音及错序/邻键候选；英文补全 |
| 九宫格 | 标准 ABC/DEF 数字键映射中文拼音，例如 `64426` 对应 `nihao`，候选可选择“你好”；切换英文时显示字母键盘 |
| 手写 | 在画板上写字，停笔约 800 毫秒后显示候选，点选确认输入；可撤销一笔、清除或主动识别。当前接入中文、英文模型 |

顶部预览与实际字母、九宫格键盘共用布局代码。选择模式、主题、符号位置和滑动方向会即时刷新预览；点击应用才保存设置。预览不会读取聊天或调用你配置的 API。

手写首次点击**下载手写模型**，需要网络连接。模型下载后，笔画在本机识别。每种语言的模型约占 20 MB，具体大小由模型版本决定，见 [Google 官方模型说明](https://developers.google.com/ml-kit/vision/digital-ink-recognition/android)。下载失败时可在同一位置重试。

手写中文字有可确定的词库拼音时，可以参与现有词库学习；未知字词仍可直接输入。手写识别候选由本地模型产生。

## 快捷符号

外观设置中可以选择：

- **符号在上方／符号在下方**：改变 26 键上的小字位置。字母和符号分别预留绘制空间，并按可用空间缩放字母。
- **上滑输入符号／下滑输入符号**：选择符号手势方向。
- **显示快捷符号栏**：三种模式都可显示常用标点和符号，直接点选。

例如 `q` 键对应 `1`。普通点按输入 `q`；按设置方向滑动或长按输入 `1`。手势成立后取消普通点击，避免一次滑动同时输入符号和字母。长按已输入符号时，抬手滑动也不会再次输入同一个符号。

本次把“26 键上下方一点”实现为**快捷符号小字位于字母上方或下方**。

## 持续保存输入记忆

路径：应用 → **输入与词库设置** → **记住常用词与输入习惯**。

确认上屏的词语、使用次数、使用时间和前后搭配写入本机 SQLite 数据库。退出应用、重启和正常覆盖更新不会主动删除记忆，也不再因为超过原来的 2000 个词或 1200 个搭配而自动淘汰旧记录。

**清空用户词库和学习记录**按钮会先要求确认，然后删除学习词语、前后搭配和手动添加的词条，保留 API 设置、界面语言和键盘外观。清空后再次调出键盘，个人候选缓存也会失效。关闭记忆开关只暂停学习和个人排序，保存过的记录仍在。

清除应用数据、卸载应用会删除本机记忆。普通打字不调用你配置的 API；密码、私密输入框及禁止个性化学习的输入框不参与学习。

## 这次优化如何改善打字

这些是本工程新增的能力与实现改进。

1. **更贴近近期习惯。** 中文候选把使用次数与最近使用时间结合起来。排序权重的近期部分以 30 天为半衰期，历史频次参与权重的上限是 64；旧记录持续保存，旧习惯的排序影响逐渐降低，避免早期常用词一直排在新习惯前面。
2. **参考前一个词。** 学习“我 → 知道”“老师 → 指导”等搭配后，输入相同的 `zhidao` 可以得到不同的同音词排序。九宫格也共享这套搭配记忆。这是本机统计排序，准确度取决于词库和你确认过的词。
3. **减少重复解码。** 最多缓存 24 组输入与前词查询，供退格、光标回调等重复查询复用。学习、模糊拼音配置变化或清空记忆会使缓存失效。用户词前缀查询使用有序索引。
4. **保留选择权。** 正常输入候选优先于纠错候选；错序 `ekshi`、邻键误触 `kwshi` 可提供“可是”。逐词候选按实际消耗的输入长度处理剩余拼音，原文仍可选择，不直接替用户把输入全部改掉。
5. **让布局适应习惯。** 三种模式、符号位置与手势方向独立保存，可以先在预览中体验，再应用到实际键盘。26 键和九宫格共享用户词与前词搭配数据。

## 界面语言

应用 → **应用语言**：中文、English、日本語、Español、한국어、Deutsch，以及跟随系统。

提供六种界面语言。跟随尚未提供翻译的系统语言时显示英语。Android 13 及以上接入系统应用语言设置；Android 11、12 使用应用内保存的语言选择，参见 [Android 官方应用语言文档](https://developer.android.com/guide/topics/resources/app-languages)。

界面语言更改菜单、按钮和提示。候选词、实际输入、聊天内容和 AI 回复保留原文。日语、韩语等界面翻译不会自动增加对应语言的专用输入引擎。全球所有语言尚未覆盖，新语种需要继续补充翻译及对应界面验证。

## 你可以亲手参与的试打

1. 选择 26 键、符号在上方、上滑输入符号，点一次 `q`，再上滑一次 `q`，观察字母与符号是否容易区分。然后试下方小字和下滑，选你更顺手的组合。
2. 选择九宫格，输入 `64426`，点“你好”。再试一句常用表达，观察候选顺序和误触率。
3. 选择手写，首次下载模型，写“一”，点候选。试试撤销、清除和你自己的笔迹。
4. 在输入与词库设置中添加“刻意 / ke yi”，回到键盘输入 `keyi`。多次确认你常用的同音词，关闭再重新打开应用，观察词库和候选是否保留。
5. 换一种界面语言，再切回中文，检查你选好的模式和个人词库仍在。

按键高度可以从 40 到 58 dp 调整；先用默认高度，再根据手指大小和屏幕尺寸调整。真机的误触率、笔迹识别和触感反馈需要你实际试打来确认。
