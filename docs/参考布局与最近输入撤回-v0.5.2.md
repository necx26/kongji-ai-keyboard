# v0.5.2：参考布局与最近输入撤回

本版按用户提供的键盘照片重排 26 键：四排主按键，居中错位的第二排，两侧较宽的大写与删除键，以及底部键盘切换、剪贴板入口。26 键不再显示额外的快捷符号横排。白色、深色和照片背景继续可用。

## 键位与触摸

- 底排从左到右是「123、逗号、波形大键、中英切换、换行」。波形大键执行空格，没有新增语音识别功能。
- 数字和符号小字按照片中的对应位置排列，字母沿设置方向滑动可输入小字对应的符号。
- 按键保留可见间距，但按下缝隙时，按距离分配给最近的按键；第二排两侧的错位区域也能输入。
- 按下后固定所属按键，松手确认；不会在横向滑动时跳到另一字母。取消触摸不输出。
- 所有可用按键按下时触发轻震动，包括候选、工具、字母、符号和底部入口。优先使用系统键盘反馈，不可用时在具有震动器的设备上使用短震动。已移除应用内的关闭震动开关。
- 九宫格和手写继续可用，手写画布保留笔画触摸，不会被附近按钮截获。

新版首次载入使用与照片一致的标准全宽布局；后续仍可在「外观」拖拽位置及大小。输入记忆、模型配置、界面语言和照片继续保留。

## 删除键的三种动作

| 操作 | 行为 |
| --- | --- |
| 点按删除键 | 删除光标前一个字符，或删除选中的文字 |
| 长按删除键 | 一个字符一个字符删除，松手或取消后停止 |
| 上滑删除键 | 有未确认拼音时，只删除这段拼音；否则删除刚确认的词、短语或刚插入的文字 |
| 下滑删除键 | 恢复最近一次上滑删除的内容、光标和拼音编辑状态 |
| 滑回原处 | 恢复普通点按；重新停留才会进入长按删除 |
| 取消手势 | 不执行上滑删除或撤回 |

回车键显示为「换行」，保留所在输入框的原行为（换行、搜索或发送），不再承载删除/撤回手势。

例如输入框原有「前文」，输入 `nihao` 后上滑删除，保留「前文」；下滑恢复为「前文nihao」，继续输入不会重复拼音。如果已经点选「你好」，上滑只删除「你好」，下滑恢复「你好」。

不能从打开输入框时已有的文字猜测“刚输入的词”。上滑无可删除的新输入时保留原文；连续上滑不会接着删除更早的词。删除后输入或粘贴新内容、切换输入框或隐藏键盘后，旧恢复记录不能覆盖新的输入。恢复后的词可以再次上滑删除。

临时删除记录只在当前输入会话的内存中，不写入输入词库、剪贴板或 API。密码输入框、无法提供完整文字的输入框不执行组合删除/撤回。

## 自检中修复的问题

慢慢上滑时，380 ms 的长按计时可能早于 18 dp 的滑动选择阈值，导致先删几个字符再识别为上滑。本版在明显上下移动开始时就暂停长按计时，达到选择阈值后只更新小预览，松手才执行对应操作。真实模拟器复现和附着按键事件回归均验证此情况。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| `KeyboardLayout.java` | 照片中的四排键位、符号、底部入口、删除键手势 |
| `KeyboardIcons.java` | 大写、删除、波形、中英、键盘、剪贴板矢量图标 |
| `KeyboardFrame.java` | 最近按键触点分配、固定手势归属、图形尺寸编辑 |
| `Glass.java` | 松手确认、慢滑与长按协调、小预览、按键震动 |
| `RecentInput.java` | 刚确认的输入范围，不猜测旧文字 |
| `DraftUndo.java` | 一次范围删除和恢复，前后文字、新输入及输入框归属校验 |
| `AiInputService.java` | 编辑范围记录、拼音状态恢复、剪贴板预览和粘贴 |
