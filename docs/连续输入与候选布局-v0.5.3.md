# v0.5.3：连续输入与候选布局

## 连续按键

按住 A 尚未松开，又按下 B 时，立即确认 A，B 成为新的待确认按键。B 松开时确认 B；如果先按下 C，就先确认 B。已经确认过的手指抬起时不再输出，输入顺序按按下顺序排列。上滑符号仍保留：确认前已经选中的符号会按当前选择输出。

修复原因：原键盘容器只保存一个触摸目标，并将包含多个手指的事件直接传给第一个按键；第二次按下没有建立新目标。本版识别每个手指的 ID，给当前待确认按键发送独立事件，保留旧手指释放的去重状态。

## 删除与回车

| 操作 | 行为 |
| --- | --- |
| 删除键点按 | 删除一个字符或选中的文字 |
| 删除键长按 | 逐字删除，松手停止 |
| 第一次上滑 | 删除当前拼音，或刚确认的词、短语 |
| 删除后再次上滑 | 没有新输入且文字、光标没有变化时，清空整框文字 |
| 下滑 | 恢复最近一次上滑删除；整框清空也可恢复 |
| 有待确认字母时点回车 | 直接确认原字母，不选中文候选，不额外换行 |
| 没有待确认内容时点回车 | 执行输入框原有的换行、发送或搜索动作 |

删除键滑动不显示悬浮块、Toast 或确认弹窗。新输入、外部粘贴、光标移动、切换输入框、隐藏键盘会使旧删除状态不再可用；不会将打开输入框时已有的文字当成最近输入。无可恢复内容时，下滑不改变文字。

## 外观设置

进入首页「外观」：

- 「候选词大小」提供极小、小、中、大、极大五档滑条，也可点按滑条下的档位。字号和候选按钮高度一起调整，样例立即更新。
- 「底部按钮位置」提供两侧、靠左、靠右，键盘预览立即更新。底部图标区域由原先 56 dp 改为 36 dp，图标缩小并下移。
- 点击「应用到键盘」或「应用并试打」才保存。原有键盘拖拽、主题、照片背景继续可用。

候选栏高度包含按钮上下边距，避免底部被第一排按键遮住。展开候选的行高随字号变化，底部保留间距和滚动区域。

## 应用图标

采用用户提供的 KJ 图片生成普通图标与 Android 自适应图标。只做资源尺寸适配，保留图片内容与配色。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| `KeyboardFrame.java` | 多指连续按键、按下顺序、旧手指释放去重 |
| `Glass.java` | 当前按键确认、滑动符号、删除长按、轻震动 |
| `AiInputService.java` | 两段删除、撤回、回车原文确认、候选栏排版 |
| `CandidateLayout.java` | 五档候选字号及配套高度 |
| `AppearanceActivity.java` | 滑条、档位预览、底部位置选择 |
| `KeyboardStyle.java` | 外观保存与恢复 |
| `res/mipmap-anydpi-v26/ic_launcher.xml` | 自适应桌面图标 |
