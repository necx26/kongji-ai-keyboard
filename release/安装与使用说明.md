# 控机 AI 输入法 v0.5.0

安装包：`控机AI输入法-v0.5.0.apk`。需要 Android 11 或以上。

## 安装

1. 把 APK 传到手机并打开安装。同签名旧版可直接覆盖，保留输入记忆和 API 配置，不需要先卸载。
2. 打开应用，点击「开启输入法」，在系统中启用「控机 AI 输入法」。
3. 返回应用，点击「切换到控机 AI 输入法」，选择本输入法。
4. 打开「键盘练习页」试打。普通输入无需 Root、API 或屏幕读取权限。

## 新版外观编辑

进入「私人定制键盘外观」，选择白色或深色。点击「拖拽编辑」，直接拖动键盘调整位置；拖右下角圆形手柄改变宽度和高度。点「结束编辑」后可试按键，再点击「应用到键盘」保存。

「导入照片背景」通过系统选择器选一张照片，应用保存本机副本。「移除照片背景」不会删除相册原图。未点击应用的修改不会覆盖现有设置。

「快捷符号」可展开设置符号小字位置、上滑或下滑方向。普通字母松手确认；沿配置方向滑动时，按键上方的小块显示当前选择，松手输出一次。删除键长按逐字删除，松手停止。

## 输入记忆和 AI 回复

输入记忆持续保存在应用内。「输入与词库设置」可暂停记忆或主动清空。应用覆盖更新保留记忆；卸载或清除应用数据会移除记忆。

AI 回复需要填写自己的模型接口并按需启用屏幕读取服务。点击「帮我回答」读取当前可见内容，检查预览，点击「生成回复」，选一条填入输入框，再自行检查发送。
