# Dictionary sources for Kongji AI Keyboard 0.3.0

Chinese dictionary: rime/rime-pinyin-simp, commit 0c6861ef7420ee780270ca6d993d18d4101049d0.
Original file: https://raw.githubusercontent.com/rime/rime-pinyin-simp/0c6861ef7420ee780270ca6d993d18d4101049d0/pinyin_simp.dict.yaml
The imported file is unmodified; its header attributes Android Pinyin IME. Apache License 2.0 and upstream AUTHORS are included in this directory.

English base words: en-wl/wordlist SCOWL/ESDB, commit 1e5b7d3a72f47a71da5d28686c1dd4b397178485.
Original file: https://raw.githubusercontent.com/en-wl/wordlist/1e5b7d3a72f47a71da5d28686c1dd4b397178485/scowl-pre.txt
Derived word list filters size <= 40, lowercase ASCII base words, and American dialect where labeled. Local relative ranking weights and some locally authored common words/inflections were added; these weights are not measured upstream corpus frequencies. Full upstream copyright and license notices are included in SCOWL-Copyright.txt.

chat_phrases.tsv and next_words.tsv are locally authored supplements. The Java input decoder is independently implemented, without librime or HeliBoard code.
